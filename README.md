# Социальная сеть: Crazy Runners (Домашнее задание)

Реализация базовой функциональности социальной сети: регистрация, авторизация и просмотр анкет пользователей.

## Технологический стек

- **Язык:** Python 3.9+
- **Фреймворк:** FastAPI
- **База данных:** PostgreSQL
- **Безопасность:** passlib (bcrypt), PyJWT
- **Инструменты:** psycopg2 (без ORM)

## Запуск приложения локально

1.  **Создайте базу данных PostgreSQL:**
    ```bash
    createdb social_network
    ```
2.  **Создайте таблицы:**
    Выполните SQL-скрипт из файла `init_db.sql`:
    ```bash
    psql -d social_network -f init_db.sql
    ```
3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Настройте переменные окружения:**
    Создайте файл `.env` в корне проекта на основе примера:
    ```bash
    cp .env.example .env
    ```
    Заполните в файле `.env` актуальные данные для подключения к вашей БД.

5.  **Запустите сервер:**
    ```bash
    uvicorn app.main:app --reload
    ```
    Приложение доступно по адресу `http://127.0.0.1:8000`.

## Работа с API

Интерактивная документация доступна по адресу:
`http://127.0.0.1:8000/docs`

Для тестирования через Postman используйте коллекцию `social_network.postman_collection.json`.

### Порядок запросов в Postman:
1.  Импортируйте коллекцию.
2.  Выполните `Register` для создания пользователя.
3.  Выполните `Login`. Скопируйте полученный `access_token`.
4.  Зайдите в настройки коллекции (Variables), вставьте токен в поле `access_token`.
5.  Выполните запрос `Get User`.

## Структура проекта

- `app/` — основная логика приложения.
  - `main.py` — роутинг и эндпоинты.
  - `auth.py` — логика хеширования паролей и JWT.
  - `db.py` — подключение к PostgreSQL.
  - `queries.py` — параметризованные SQL-запросы.
  - `models.py` — Pydantic-схемы.
- `init_db.sql` — скрипт инициализации БД.
- `social_network.postman_collection.json` — коллекция для тестирования API.
